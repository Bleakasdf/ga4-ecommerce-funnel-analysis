# Power BI

Open `project/GA4ProductFunnel.pbip` in Power BI Desktop.

The report has two pages:

1. **Funnel decision** — headline funnel loss, conversion, and weekly trend.
2. **Segment priorities** — channel and product-category opportunity scenarios.

If the repository was moved to another folder:

1. Open **Transform data → Manage parameters**.
2. Set `DataFolder` to the local `data/powerbi` folder.
3. Select **Refresh**.

The project uses UTF-8 CSV files and English field names.
